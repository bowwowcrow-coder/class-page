1기본 정보

학생이 폰 홈 화면에 추가하면 탭 이름의 첫 글자가 아이콘에 들어갑니다.

수업마다 공지, 과제 옆에 붙는 탭입니다. 링크나 참고할 것을 모아 둡니다. 아무것도 넣지 않은 수업에서는 학생에게 이 탭이 보이지 않습니다.

2화면 색

포인트 색
배경 색감

원판에서 한 점을 누르거나 끌어서 고릅니다. 가운데로 갈수록 무채색, 바깥으로 갈수록 선명해집니다. 어떤 색을 골라도 글자가 읽히도록 밝기는 자동으로 맞춥니다.

3교사 비밀번호

교사 화면에 들어갈 때 씁니다. 비워 두면 지금 비밀번호가 유지됩니다.

4학번 구조

우리 학교는 어떤 구조인지 모르겠어요

학생들이 쓰는 학번을 하나 떠올려 보세요.

  • 10712처럼 5자리 (1학년 07반 12번) → 학년 1, 반 2, 번호 2
  • 1712처럼 4자리 (1학년 7반 12번) → 학년 1, 반 1, 번호 2
  • 한 반이 100명을 넘는 경우만 번호를 3으로 합니다.

학생을 한 명이라도 넣은 뒤에는 바꿀 수 없으니 여기서 먼저 정해 주세요.

5처음 접속할 때 본인 확인

학생이 처음 PIN을 만들 때 한 번만 입력합니다. 값은 아래 명단의 "확인코드"에 넣습니다.

왜 필요한가요? 무엇을 고르면 좋나요?

학번과 이름은 친구들도 알기 때문에, 본인만 아는 값을 하나 더 물어 남이 대신 PIN을 만들지 못하게 합니다.

  • 휴대폰 번호 뒤 4자리: 명단에 전화번호를 붙여넣으면 뒤 4자리만 저장됩니다. 가장 간편합니다.
  • 생년월일 6자리: 전화번호가 없는 학생이 있을 때 씁니다.
  • 선생님이 나눠 준 코드: 가장 안전하지만 학생마다 코드를 정해 나눠 줘야 합니다.

한 번 PIN을 만든 뒤에는 다시 묻지 않습니다.

6수업과 학급

"반 전체 배정"에 1-7, 1-8 처럼 학년-반을 적으면 그 반 학생 전원이 자동으로 들어갑니다. 선택 과목처럼 일부만 듣는 수업은 비워 두고, 아래 명단에서 수업을 골라 붙여넣습니다. 담임 반은 종류를 "학급"으로 하면 공지·제출 공간이 따로 생깁니다.

내 경우에는 어떻게 넣나요? (유형별 예시)
  • 여러 반에 같은 과목을 가르친다
    수업 1개. 반 전체 배정에 1-7, 1-8처럼 맡은 반을 모두 적습니다.
  • 선택과목이라 신청한 학생만 듣는다
    수업 1개. 반 전체 배정은 비워 둡니다. 명단 양식의 "수업" 칸에 이 수업 이름을 적은 학생만 들어옵니다.
  • 담임만 맡는다
    수업 1개, 종류를 "학급"으로. 반 전체 배정에 내 반(예: 3-2)을 적습니다.
  • 교과도 가르치고 담임도 맡는다
    위의 것을 각각 하나씩 추가합니다. 학생은 자기에게 해당하는 것만 보게 됩니다.
  • 과목이 여러 개다
    과목마다 "+ 수업 추가"를 누릅니다.

과제는 여기서 만들지 않습니다. 설정이 끝난 뒤 웹앱의 교사 화면에서 "+ 새 과제"로 만듭니다.

7학생 명단

① 양식 받기
② 채우기 엑셀에서 열어 학년, 반, 번호, 이름, 확인코드를 적고 저장합니다.
③ 올리기

이미 있는 학생은 이름과 확인코드만 고치고 PIN은 그대로 둡니다. 같은 파일을 고쳐서 다시 올려도 됩니다.

파일 없이 직접 붙여넣기

확인코드 칸은 비워 둬도 되고, 전화번호 전체를 붙여넣으면 뒤 4자리만 저장합니다.

8웹앱 주소 만들고 학생에게 열어 주기

학생에게 보여 줄 QR

폰은 QR로, 노트북은 주소 링크로 들어옵니다. 한 번 들어온 뒤 홈 화면에 추가하거나 북마크해 두게 하면 다음부터는 바로 열 수 있습니다.

웹앱 주소 만드는 방법 (처음 한 번)
  1. 이 스프레드시트 위쪽 메뉴에서 확장 프로그램 > Apps Script를 엽니다.
  2. 새로 열린 편집기의 오른쪽 위에서 배포 > 새 배포를 누릅니다.
  3. 왼쪽 톱니바퀴에서 웹 앱을 고르고, 액세스 권한을 모든 사용자로 바꾼 뒤 배포를 누릅니다. "액세스 승인"을 묻는 창이 뜨면: 내 계정 선택 > 고급 > "(안전하지 않음)으로 이동" > 허용.
  4. 나온 웹 앱 URL을 한 번 눌러 엽니다. 로그인 화면이 뜨면 성공입니다.
  5. 이 창으로 돌아와 아래 새로 확인을 누르면 QR이 나타납니다. 안 나오면 주소를 복사해 붙여넣으세요.

화면에 보이는 글자는 구글이 바꾸면 조금 다를 수 있습니다. 나중에 코드를 고쳤을 때는 "새 배포"가 아니라 배포 관리 > 연필 > 새 버전으로 올려야 주소가 그대로 유지됩니다.
